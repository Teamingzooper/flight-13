# Flight 13 — Milestone 3: 3D Cabin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace the full-page 2D TV with a first-person 3D airliner cabin: you sit in your seat, look
around, and lean into the seatback screen to use the same TV interface. Day/night lighting follows the
game phase; passengers (placeholder mannequins until Milestone 4) sit where the game says they sit.

**Architecture:** `src/world/` holds a framework-free Three.js layer. `layout.ts` is pure cabin math
(tested). `Cabin3D` owns renderer, scene, camera, post-processing and the render loop, and exposes
`update(state)`, `setLeaning()`, `resize()`, `dispose()` and an `onScreenClick` callback. Scene parts
(`cabin`, `seats`, `cart`, `avatars`, `lighting`, `screen`) each build one thing and expose small update
methods. `World.tsx` mounts `Cabin3D`, draws the minimal HUD, and shows the existing `TV` in an
`embedded` mode over the seatback screen when leaning in. 2D mode stays available as a fallback and a toggle.

**Deviation from the usual plan format:** visual modules are tuned iteratively against screenshots, so
this plan specifies their interfaces and acceptance checks; complete code lives in the repository.
Pure logic (`layout.ts`) is test-first with full code below.

**Tech Stack:** three 0.186, postprocessing 6.39 (bloom, vignette, noise, tone mapping, SMAA), Preact.

---

## Scene conventions

- Metres. `y` is up. Row 1 is at `z = 0`; rows run toward `+z`; passengers face `-z` (the galley).
- Seat pitch 0.82 m, seat width 0.46 m, aisle 0.5 m, cabin half-width 1.82 m, seated eye height 1.12 m.
- Column centres: A −1.40, B −0.94, C −0.48, aisle 0, D 0.48, E 0.94, F 1.40.
- Your screen is on the back of the seat ahead (row 1: a bulkhead screen), about 0.6 m from your eyes.

### Task 1: Cabin layout math (test-first)

**Files:** Create `src/world/layout.ts`; Test `src/world/layout.test.ts`

```ts file=src/world/layout.test.ts
import { describe, expect, it } from 'vitest';
import { CABIN_HALF_WIDTH, PITCH, SEAT_WIDTH, colX, eyePosition, rowZ, screenPose, seatPose } from './layout';

describe('cabin layout', () => {
  it('places columns symmetrically around the aisle', () => {
    expect(colX(3)).toBe(0);
    for (const [l, r] of [[0, 6], [1, 5], [2, 4]]) expect(colX(l)).toBeCloseTo(-colX(r));
    expect(colX(2) - colX(1)).toBeCloseTo(SEAT_WIDTH);
    expect(colX(0) - SEAT_WIDTH / 2).toBeGreaterThan(-CABIN_HALF_WIDTH);
  });

  it('spaces rows by the seat pitch', () => {
    expect(rowZ(1)).toBe(0);
    expect(rowZ(5) - rowZ(4)).toBeCloseTo(PITCH);
    expect(seatPose('3D')).toEqual({ x: colX(4), z: rowZ(3) });
  });

  it('puts every screen within arm reach in front of its passenger', () => {
    for (const seat of ['1A', '2C', '7F', '12D']) {
      const eye = eyePosition(seat);
      const screen = screenPose(seat);
      const reach = eye.z - screen.z;
      expect(screen.x).toBeCloseTo(eye.x);
      expect(reach).toBeGreaterThan(0.45);
      expect(reach).toBeLessThan(0.8);
      expect(screen.y).toBeLessThan(eye.y);
    }
  });
});
```

```ts file=src/world/layout.ts
import { grid, type SeatId } from '../engine';

/** Metres. Row 1 is at z = 0, rows run toward +z, passengers face -z. */
export const PITCH = 0.82;
export const SEAT_WIDTH = 0.46;
export const AISLE_WIDTH = 0.5;
export const CABIN_HALF_WIDTH = 1.82;
export const EYE_HEIGHT = 1.12;
export const SCREEN_HEIGHT = 0.98;
/** Galley bulkhead in front of row 1. */
export const BULKHEAD_Z = -0.62;

/** x centre of grid column 0..6 (3 is the aisle). */
export function colX(col: number): number {
  if (col === grid.AISLE_COL) return 0;
  const side = col < grid.AISLE_COL ? -1 : 1;
  const fromAisle = col < grid.AISLE_COL ? grid.AISLE_COL - 1 - col : col - grid.AISLE_COL - 1;
  return side * (AISLE_WIDTH / 2 + SEAT_WIDTH / 2 + fromAisle * SEAT_WIDTH);
}

export function rowZ(row: number): number {
  return (row - 1) * PITCH;
}

export function seatPose(id: SeatId): { x: number; z: number } {
  const cell = grid.parseSeat(id);
  if (!cell) throw new Error(`Bad seat ${id}`);
  return { x: colX(cell.col), z: rowZ(cell.row) };
}

/** Where a seated passenger's eyes are. */
export function eyePosition(id: SeatId): { x: number; y: number; z: number } {
  const { x, z } = seatPose(id);
  return { x, y: EYE_HEIGHT, z: z + 0.1 };
}

/** Centre of the screen a passenger uses: the back of the seat ahead, or the bulkhead for row 1. */
export function screenPose(id: SeatId): { x: number; y: number; z: number } {
  const cell = grid.parseSeat(id);
  if (!cell) throw new Error(`Bad seat ${id}`);
  const x = colX(cell.col);
  return cell.row > 1 ? { x, y: SCREEN_HEIGHT, z: rowZ(cell.row - 1) + 0.3 } : { x, y: SCREEN_HEIGHT, z: BULKHEAD_Z + 0.03 };
}
```

### Task 2: Procedural textures and materials

**File:** `src/world/textures.ts` — canvas-generated textures: carpet, seat fabric, day sky, night sky,
idle IFE screen, exit sign, lavatory sign. No image files.
**Acceptance:** every texture is a `CanvasTexture` in sRGB, power-of-two sized, mipmapped.

### Task 3: Static cabin

**File:** `src/world/scene/cabin.ts` — `buildCabin(rows)` returns `{ group, windows, coves, floorLights,
exitSigns, readingLights }`: floor with carpet, lower side walls, per-row window panels with openings,
window glass (sky material), shades at random heights, curved upper walls, overhead bins with seams, cove
light strips, ceiling, passenger service units with reading lights and seatbelt signs, galley bulkhead with
curtain and exit sign, rear lavatory door with WC sign and crew area.
**Acceptance:** screenshot from a mid-cabin seat reads clearly as an airliner cabin.

### Task 4: Seats and the drink cart

**Files:** `src/world/scene/seats.ts` — instanced seats for all 6 × rows positions (cushion, reclined
back, headrest cover, armrests, legs, seatback screen); `setScreen(seat, material)` swaps the local
screen. `src/world/scene/cart.ts` — aluminium trolley that eases to `cartRow`; hidden once destroyed.
**Acceptance:** draw calls stay under ~120 for a 12-row cabin.

### Task 5: Lighting rig

**File:** `src/world/lighting.ts` — hemisphere + ambient + shadowed directional (sun or moon through the
windows) + emissive strips; `setMode('day' | 'night' | 'dim')` eases all intensities and colours over ~2 s.
Night: blue moonlight, aisle floor lights, exit signs, a few reading lights, the local screen's glow.
**Acceptance:** day and night screenshots look clearly different and readable.

### Task 6: Camera, controls and the lean-in

**File:** `src/world/controls.ts` — seated look controls: pointer lock on desktop (click to look), drag on
touch, yaw ±140°, pitch −60°..45°, smoothed; breathing sway; `leanTo(screen)` / `sitBack()` eased
transitions; `moveTo(seat)` walks the camera up, along the aisle and into the new seat.
**Acceptance:** looking around is smooth; leaning in frames the screen; seat changes animate.

### Task 7: Screen texture, placeholder passengers, Cabin3D and World

**Files:** `src/world/screen.ts` (in-world TV canvas: phase, countdown, mini seat map, "click to use"),
`src/world/scene/avatars.ts` (placeholder mannequins coloured by look; dead slump; restrained hidden),
`src/world/Cabin3D.ts` (renderer, composer, loop, raycast clicks on the local screen, update from
`ClientState`), `src/world/World.tsx` (mounts Cabin3D, HUD, embedded TV while leaning, 2D toggle).
Modify `src/tv/TV.tsx` (embedded mode, back-to-seat button) and `src/app/pages/Flight.tsx` (3D by default
when WebGL works; 2D preference stored locally).
**Acceptance:** a full game can be played in 3D across two tabs; the TV works when leaned in; 2D toggle works.
